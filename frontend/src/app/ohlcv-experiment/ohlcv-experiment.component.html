SCORING REFERENCE

How P1–P5 are calculated

P1 · 12-Month Momentum 0–2 points

Measures whether the asset is a genuine long-term leader using its 252-day return rank.

2Top-tier long-term winner12M rank ≤ 10
1Solid long-term performer12M rank ≤ 25
0Not a long-term leader12M rank > 25

P2 · Medium + Short-Term Confirmation 0–2 points

Checks whether the 6-month and 3-month windows both confirm that momentum is still running.

2Confirmed on both timeframes6M rank ≤ 10 and 3M rank ≤ 10
1Reasonable confirmation6M rank ≤ 25 and 3M rank ≤ 25
0Recent momentum has broken downEither rank fails the ≤ 25 test

P3 · Shape / Consistency 0–2 points

Tests whether the return pattern is persistent and healthy instead of a fresh spike or front-loaded fade.

2Persistent or accelerating with a baseRank spread ≤ 10 and 12M ≤ 20; or 12M ≤ 15, 6M ≤ 10 and 3M ≤ 12
1Decent shape12M ≤ 30, 6M ≤ 10 and 3M ≤ 15; or all ranks ≤ 25
0Broken shape12M > 40; hard fade; or front-loaded momentum
Hard fade: 3M rank ≥ 2× 12M rank and > 20. Front-loaded: 6M rank ≥ 12M rank + 12 and > 15.

P4 · Trend Health from OHLCV 0–2 points

Checks whether price structure is technically sound independently of return ranks.

2Strong aligned uptrendClose > SMA50 > SMA200, SMA50 rising, within 8% of 52-week high
1Acceptable trendNot broken, but not all strong conditions pass
0Broken trendClose < SMA50 or more than 15% below 52-week high

P5 · Entry Timing 0–2 points

Uses volatility-adjusted extension and volume confirmation to avoid chasing.

2Ideal entry with confirmationExtension < 1.5 and volume confirmation passes
1Acceptable entryExtension is below 2.5 without the ideal setup
0Bad timing—do not chaseDaily return ≥ 8% or extension ≥ 2.5
Volume confirms when vol20 ≥ vol50 or last volume ≥ 1.5× vol20.

How they combine

P1 + P2 + P3 is the 0–6 pure momentum signal. P4 + P5 is the 0–4 technical overlay. For a Core asset, P5 determines the final action: 2 = Buy Now, 1 = Scale In, and 0 = Wait for Dip.
